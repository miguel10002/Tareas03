# Alcance del proyecto: 26 historias de usuario

Se incluyen las historias HU-01 a HU-26 de las épicas: acceso, ventas, productos, inventario, usuarios y reportes.

**HU-27 (configuración de datos básicos del negocio) queda fuera del alcance actual.**

Este documento delimita el alcance, pero no certifica la implementación ni las pruebas de las 26 historias.

## Antes de publicar
- Repositorio privado mientras existan credenciales de demostración y controles de autorización pendientes.
- Nunca subir archivos `.env`, dependencias `node_modules` ni datos operativos de `backend/data`.
- Ejecutar `npm ci`, `npm run lint` y `npm run build` en el equipo de desarrollo.
